# Workshop Energy Cost Estimator ⚡

A Python-based program that calculates workshop machine energy consumption and electricity costs.

### Project Information
- **Name:** Onyekwere Zoe Kosiobabire
- **Department:** Mechatronics Engineering
- **Institution:** YABATECH
- **Class:** ND2
- **Course:** CTE213

### Features
- Automatic selection of 12 workshop machines.
- Automatic machine power ratings.
- Daily and monthly energy calculations.
- Electricity cost estimation.
- Identification of high-energy-consuming machines.
- Workshop energy classification.
- PLC-based energy-saving recommendations.

### Technologies Used
- Python 3
- Functions
- Lists and Dictionaries
- Loops
- Conditional Statements
- Exception Handling

### Energy Formula
Energy (kWh) = (Power (W) / 1000) × Operating Hours

### Project Objective
To estimate workshop energy consumption, monitor electricity costs, and encourage efficient energy management through PLC-based recommendations.
